# 📊 Reflection: AI-Based Sentiment Analysis Tool

## 💭 What I Learned
I learned how AI can analyze text data and extract meaningful insights using sentiment analysis. By combining web scraping and AI models, it’s possible to track how people feel about financial markets in real time.

This showed me how AI can turn unstructured data like news into useful information.

---

## 🔍 What Surprised Me
I was surprised by how accurate sentiment models can be when analyzing financial news. It’s interesting how AI can detect trends based on tone, keywords, and patterns.

---

## ⚠️ Challenges I Noticed
- Accuracy depends on the quality of data  
- Financial sentiment can change quickly  
- Models may misinterpret context or sarcasm  

---

## 🔗 Real-World Connection
This type of system is used in:
- Stock market analysis  
- Investment decision-making  
- Financial forecasting  

Many companies rely on sentiment data to guide strategies.

---

## 🧠 How My Thinking Changed
Before, I thought AI mainly worked with structured data. Now I see that it can also understand and analyze human language effectively.

---

## 💡 Key Insight
AI can transform raw text data into actionable insights, making it a powerful tool for decision-making.
