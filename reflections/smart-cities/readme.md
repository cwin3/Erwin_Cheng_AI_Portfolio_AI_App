# 🌆 Reflection: Smart Cities & Transportation

## 💭 What I Learned
AI helps cities become more efficient by using real-time data to manage traffic, reduce congestion, and improve transportation systems.

---

## 🔍 What Surprised Me
I was surprised that AI can predict traffic before it even happens, not just react to it.

---

## ⚠️ Challenges I Noticed
- Privacy concerns  
- Cybersecurity risks  
- High infrastructure costs  

---

## 🔗 Real-World Connection
Smart traffic lights, parking systems, and navigation apps already use AI to improve daily commuting.

---

## 🧠 How My Thinking Changed
I now think of cities as systems that can be optimized using data, not just physical infrastructure.
